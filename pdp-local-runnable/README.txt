PDP local runnable (no Python needed)

1) Put files:
   - pdp-input
   - pdp-crawl-input
   - pdp-masters

2) Run (recommended):
   ./run_pdp_local.sh

   Or run binary directly:
   ./pdp-local-runner

3) Output:
   pdp-run-output

Optional helper scripts in this same folder:
- ./build_pdp_executable.sh   (rebuild local binary from repo source/venv)
- ./package_pdp_runner.sh     (create share zip one level above this folder)
